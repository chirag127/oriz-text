About oriz-text

Text toolkit — case, count, dedupe, sort, slugify, find & replace, AI rewrite.

oriz-text is a writing-desk text toolkit that runs entirely in your browser. Type, paste, or drop a file, then run any transform — your text never leaves the page. This is the project info page; the live tool lives at text.oriz.in.

Open the live app → Source on GitHub llms.txt

Key features

  • Case: UPPER, lower, Title, Sentence, tOGGLE.
  • Programmer cases: camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE, slugify.
  • Lines: sort A→Z / Z→A / numeric, dedupe, reverse, shuffle.
  • Whitespace: trim lines, remove extra spaces, remove blank lines.
  • Reverse: characters or words.
  • Find & replace: literal or regex with $1 backrefs, ignore-case.
  • Lorem ipsum: paragraphs, sentences, or words.
  • Live meter: words, chars, lines, sentences, paragraphs, reading time.
  • AI polish (optional): grammar, summarize, rewrite, tone, translate.

Tech

  • Client-only Astro (static) with React 19 islands.
  • AI via g4f through @chirag127/oz-ai — keyless, loads on demand.
  • PWA-installable; core tools work offline.
  • 100% in-browser — no upload, no signup, free.
